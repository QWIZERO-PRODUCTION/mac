# WinNotch — «челка» для Windows

Минималистичная челка в стиле macOS у верхнего края экрана (с «ушками», как у MacBook).

## Что умеет
- **Музыка** (Spotify, Яндекс Музыка, браузер, VLC и всё, что видит системный медиаплеер Windows):
  обложка, название, исполнитель, перемотка кликом **или перетаскиванием** по полоске,
  назад / пауза / вперёд. В свёрнутом виде — мини-обложка и эквалайзер цвета обложки.
- **Уведомления**: иконка и название приложения, заголовок и текст. Клик по уведомлению — закрыть.
  Учитываются настройки Windows (уведомления/баннеры выключены — не показываем).
- **Без музыки** при наведении: время, дата, заряд батареи (на ПК без батареи — только время и дата).
- **Колесо мыши** над раскрытой челкой — громкость.
- Раскрывается с небольшой задержкой — случайное пролетание курсора по верху экрана ничего не раскрывает.
- Сама прячется, когда на основном мониторе открыта полноэкранная игра или видео.
- Иконка в трее: автозапуск, показ уведомлений, «прятать, когда ничего не происходит», выход.

## Как собрать
1. Создай репозиторий на GitHub и залей туда все файлы (папку `.github` тоже).
2. Вкладка **Actions** → **Build WinNotch** → **Run workflow**.
3. Скачай артефакт `WinNotch`, распакуй в постоянную папку (например `C:\Users\<ты>\AppData\Local\WinNotch`)
   и один раз запусти `WinNotch.exe`. Автозапуск включится сам.

Релиз с zip-файлом: `git tag v1.1 && git push --tags`.

## Заметки
- Нужна Windows 10 1809+ / Windows 11 (x64). .NET Framework 4.8 уже есть в системе, ничего ставить не надо.
- При первом запуске SmartScreen может показать «Неизвестный издатель» — это обычно для неподписанных программ:
  «Подробнее» → «Выполнить в любом случае».
- Ошибки пишутся в `%LOCALAPPDATA%\WinNotch\error.log` (до ~200 КБ).
- Фокус-ассистент («Не беспокоить») челка не определяет — для этого есть пункт «Показывать уведомления» в трее.
